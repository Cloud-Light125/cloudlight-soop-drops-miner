## 功能简介

- **多账号挂机**：可同时管理多个 SOOP 账号，一键开始或停止全部账号
- **自动进房**：无需先在浏览器观看，程序自动进入符合条件的直播间
- **三种掉宝类型**：固定型（达标即发放）、抽奖型（达标后参与抽奖）、随机型（观看期间随机发放）
- **自动选择**：按任务与分类自动匹配 `#드롭스` 直播间，可指定**优先任务**
- **手动选择**：自选链接或列表中的频道；分类不匹配时**仅警告、不阻止开始**
- **任务进度**：同一时间只能挂一个直播间，界面**只显示当前台会累计的那一种类型**的进度
- **奖励背包**：汇总各账号已领取奖励，支持复制兑换码
- **网络恢复**：连接或观看状态验证超时后自动恢复，避免账号因单次网络抖动退出
- **命令行模式**：无图形界面时可用 CLI 多账号运行（可选）
- **现代单页面**：CustomTkinter 圆角卡片、浅色/深色/跟随系统主题，账号、任务、背包与日志稳定刷新

## 重要说明：同一时间只能挂一个直播间

SOOP Drops 的观看进度按**直播间分类 / 官方频道**累计。若账号同时有多个进行中的任务（例如固定型「이터널 리턴」+ 抽奖型「아크 레이더스」），**同一时刻只能在一个匹配的直播间挂机**，只有与该台分类/官方台匹配的任务才会涨进度。

程序会在日志与界面中提示：其他任务需**换台**或**调整自动选择的优先任务**后才能累计。

## 使用说明

### 1. 添加账号

1. 在单页面顶部的 **「账号管理」** 卡片中操作
2. 在账号列表上方输入 SOOP **账号** 与 **密码**
3. 点击 **「添加账号」** 保存（登录信息写入本地，下次无需重复输入密码）

也可在点击 **「开始全部账号」** 时临时填写账号密码，程序会自动登录并保存。

### 2. 选择直播间策略

在 **「直播间」** 区域顶部有说明：**同一时间只能挂一个直播间**。请从以下三种模式中选择一种（互斥）：

| 模式 | 说明 |
|------|------|
| **自动选择**（默认） | 按进行中任务自动匹配可累计进度的直播间。可通过 **「优先任务」** 下拉指定先完成哪一个任务。 |
| **手动选择** | 从直播间列表选择，或粘贴 `https://play.sooplive.com/频道ID` / 频道 ID。若所选直播间分类与任务不一致，仍可开始运行，但对应任务进度可能不会增加。 |
| **仅守望先锋赛事频道** | 固定等待 `owesports` 官方频道开播；未开播时不自动切换到其他 `#드롭스` 频道。 |

切换模式后，可点击 **「刷新直播间」** 更新 `#드롭스` 标签下的在线直播。列表项方括号内标注掉宝类型（固定 / 抽奖 / 随机）及分类信息。

**启动顺序**：即使 mission 页暂时还没有任务，程序也会**先进房**再拉任务（部分活动需进房观看后才会出现在 mission 列表）。

### 3. 开始 / 停止挂机

1. 确认已添加至少一个账号
2. 点击页顶 **「开始全部账号」** 启动所有账号
3. 挂机过程中可在账号列表查看各账号状态、累计进度与当前直播间
4. 点击 **「停止全部账号」** 结束运行；关闭窗口前建议先停止

手动选择模式下，点击开始前若存在分类不匹配，会在日志中输出警告。

### 4. 查看任务进度

选中账号列表中的某一账号后，下方 **「任务进度」** 区域**只显示当前直播间会累计的那一种掉宝类型**（标题会显示为「任务进度 · 固定型」等），不再并排展示三种类型。

- **固定型**：观看分钟数、档位进度；官方频道或**分类固定型**（无官方台列表、需挂对应游戏分类）的提示
- **抽奖型**：各档位累计进度（需对应分类下有 `#드롭스` 在线直播）
- **随机型**：多在活动页（`/event`）展示，进 mission 后同样按分类/频道规则累计

若当前台不会累计其他进行中的任务，自动选择区域会提示需换台或调整优先任务。

### 5. 活动页与任务页

| 页面 | 含义 |
|------|------|
| **活动页** `/event` | 当前平台进行中的全部 Drops 活动目录（含随机型等） |
| **任务页** `/mission` | 该账号**已参与**、可查看进度的任务；需先进带 Drops 的直播间，观看一段时间后才会出现 |

界面可打开 Drops 官网核对；若 mission 为空但活动页有活动，属正常现象，进房挂机后会逐步加入。

### 6. 奖励背包

展开单页面中的 **「奖励背包」** 卡片，可查看所有已保存账号的奖励记录，并使用 **「复制兑换码」** / **「复制全部」**。兑换码默认掩码显示，只有复制操作读取完整值；点击 **「刷新背包」** 从服务器拉取最新数据。

### 7. 设置与主题

展开同一页面中的 **「设置」** 卡片，可配置开机自启、静默托盘、代理、自动领取、低流量模式、刷新间隔，以及跟随系统/浅色/深色主题。代理测试在后台运行，不阻塞主窗口。

## 常见问题

**Q：点了开始但没有反应？**  
请先添加账号，并确认页顶提示不是「请先添加至少一个账号」。

**Q：固定型进度不涨？**  
常见原因：① 挂错了直播间——部分固定型是**分类固定型**（如「이터널 리턴」），需挂对应**游戏分类**的 `#드롭스` 直播，而非 owesports；② 官方掉宝频道未开播；③ 活动已结束或未开放。

**Q：有多个任务，为什么只有一个在涨？**  
**同一时间只能挂一个直播间。** 当前台只匹配其中一个任务的分类/官方频道，其他任务需换台或调整「优先任务」后再刷。

**Q：抽奖型进度不涨？**  
确认是否挂在**对应游戏分类**下的 `#드롭스` 在线直播（可用「刷新列表」查看方括号内的分类标签）。

**Q：手动选择提示分类不一致，还能开始吗？**
可以。程序**只警告、不阻止**；若分类确实不匹配，进度不会增加，请换到列表中带正确分类的频道。

**Q：mission 页没有任务，但活动页有活动？**  
mission 仅显示已参与的任务。程序会先进房并自动开启 Drops 开关；观看一段时间后任务才会出现。随机型等活动可能长期只在活动页展示。

**Q：日志里出现「网络异常，正在恢复会话」？**  
这是软件的自动恢复机制。一般会重新建立连接并继续运行；若频繁出现，请检查网络或防火墙。

**Q：多账号会互相影响吗？**  
各账号独立挂机、独立计进度；直播间策略与选台设置**所有账号共用**；奖励背包页统一汇总展示。

**Q：重复双击 exe 会开两个窗口吗？**  
不会。Windows 下已运行时再次双击，会自动把已有窗口带到前台，不会启动第二个实例。

**Q：新账号点了「全部开始」却没有任务？**  
程序会在添加账号和开始挂机时**自动开启**官网 Drops 总开关并预热会话，一般无需手动打开浏览器。若日志仍提示「官网未返回 Drops 任务」，常见原因：活动限制每人仅一次（小号/重复账号）、需绑定游戏账号、或当前无进行中活动。可点 **「打开 Drops 官网」** 用该账号登录后确认。
